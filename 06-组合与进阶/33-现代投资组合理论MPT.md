# 33 现代投资组合理论（MPT）

> **这一章要让你搞懂的事**
> 1. **马科维茨**（Markowitz）发现的反直觉事实——两个**高风险**资产合在一起可能比单个**低风险**资产更稳
> 2. **相关性 ρ** 是分散化的"魔法系数"——为什么 ρ < 1 就能"白赚收益"
> 3. **有效前沿（Efficient Frontier）**：在所有可能的组合里，哪些是"白送你回报"的最优解
> 4. **切点组合**：引入"无风险资产"后，整个市场只有**一个最优风险组合**
> 5. **MPT 的局限**：理论很美，但**5 个假设在现实中都不完美**
> 6. **实操**：用 Excel 算出"沪深 300 + 中证 500 + 国债" 的最优配比
>
> **入门门槛**
> - 第 04 章：波动率、最大回撤
> - 第 06 章：资产配置基础
> - 第 22 章：ETF
>
> **声明**：本教程不构成投资建议；所有数字、组合为教学示例。

## 0. 先讲个故事

**1952 年**，25 岁的博士生**马科维茨**写了一篇 14 页的论文《Portfolio Selection》。

**当时金融学的共识**：选股票就是"挑最好的几只"——巴菲特那种基本面分析。

**马科维茨的反直觉发现**：
> "**两只高风险股票合在一起，可能比单个低风险股票更稳定**。"

这听起来荒谬——直到他用数学证明了。

**举例**（教学场景）：
- 资产 **A**：长期年化 10%，波动率 25%（高风险股）
- 资产 **B**：长期年化 10%，波动率 25%（高风险股）
- 但 A 和 B 的**走势完全相反**（相关性 ρ = -1）：A 涨时 B 跌
- **组合 50% A + 50% B**：年化 10%，波动率 **0%**！（完全对冲）

**结论**：**收益不变，风险消失**——这是金融数学上"近乎奇迹"的发现。

马科维茨用这套理论拿了 **1990 年诺贝尔经济学奖**。今天所有的"资产配置 / 基金组合 / 养老金管理"都基于 MPT。

> 这章告诉你：
> 1. **分散化不是空话** —— 是有严格数学证明的"免费午餐"
> 2. **相关性 ρ** 是核心参数 —— ρ < 1 就有"白赚的稳定性"
> 3. **有效前沿**：在所有组合中，哪些是最优解
> 4. **现实中怎么用**：算出"沪深 300 + 中证 500 + 债" 的最优配比

## 1. 风险的可分散性

### 1.1 系统性风险 vs 非系统性风险

| 类型 | 含义 | 例子 |
|---|---|---|
| **系统性风险**（不可分散） | 整个市场都受影响 | 金融危机、经济衰退、加息 |
| **非系统性风险**（可分散） | 单只资产 / 单一行业 | 公司财报、CEO 离职、行业事件 |

**铁律**：**通过多元化，非系统性风险可以"无成本"消除**；系统性风险**永远存在**。

## 2. 相关性 ρ：分散化的核心系数

### 2.1 相关性的取值

**相关性 ρ（Correlation Coefficient）**：两资产价格变化的"同步程度"。

| ρ 值 | 含义 | 例子 |
|---|---|---|
| **ρ = 1** | 完全正相关 | 同一资产 / 同行业 |
| ρ = 0.7 | 强正相关 | 沪深 300 vs 中证 500 |
| ρ = 0.3 | 弱正相关 | 股票 vs 黄金 |
| ρ = 0 | 不相关 | 沪深 300 vs 美国国债 |
| ρ = -0.5 | 中等负相关 | 长期股 vs 长期债（部分时段）|
| **ρ = -1** | 完全负相关 | 理论极限，现实没有 |

### 2.2 两资产组合的方差公式

两个资产 A 和 B，权重 $w_A$ 和 $w_B$（$w_A + w_B = 1$）：

$$
\sigma_p^2 = w_A^2 \sigma_A^2 + w_B^2 \sigma_B^2 + 2 w_A w_B \rho_{AB} \sigma_A \sigma_B
$$

**翻译成人话**：组合方差 = 各资产方差加权和 + **相关性修正项**。

**关键**：第三项含 ρ —— **ρ < 1 时这项小于"完全同步"情况** → 组合波动率降低。

### 2.3 一个直观例子

**资产 A**：年化 8%，波动 20%
**资产 B**：年化 8%，波动 20%
**权重**：50/50

| ρ | 组合波动率 |
|---|---|
| **1.0** | 20%（完全没分散）|
| **0.5** | 17.3% |
| **0.0** | 14.1% |
| **-0.5** | 10.0% |
| **-1.0** | **0%**（完全对冲）|

**翻译成人话**：相关性越低，组合波动率越低，**这就是"白赚的稳定性"**。

### 2.4 中国市场常见相关性（教学示例）

| A → | 沪深 300 | 中证 500 | 国债 | 黄金 | 标普 500 |
|---|---|---|---|---|---|
| 沪深 300 | 1.00 | 0.85 | -0.10 | 0.15 | 0.30 |
| 中证 500 | 0.85 | 1.00 | -0.05 | 0.20 | 0.25 |
| 国债 | -0.10 | -0.05 | 1.00 | 0.10 | -0.05 |
| 黄金 | 0.15 | 0.20 | 0.10 | 1.00 | 0.20 |
| 标普 500 | 0.30 | 0.25 | -0.05 | 0.20 | 1.00 |

**观察**：
- 沪深 300 ↔ 中证 500：ρ = 0.85（很相关 → **分散效果有限**）
- 沪深 300 ↔ 国债：ρ = -0.10（**很好的对冲**）
- 沪深 300 ↔ 标普 500：ρ = 0.30（**中等分散**）

**实操启示**：**国内股 + 海外股 + 国债 + 黄金**——这是最有效的分散组合。

### 3.2 三个关键点

| 点 | 含义 |
|---|---|
| **最小方差组合**（左下）| 风险最小，收益也较低 |
| **最高收益组合**（右上）| 收益最高，但风险最大 |
| **60/40 经典组合**（中间）| 平衡型，散户常用 |

### 3.3 有效前沿的"金句"

**马科维茨**：
> "**在有效前沿上的所有组合都是最优的——你应该选哪个，取决于你的风险偏好**。"

**翻译成人话**：
- 想稳健 → 选左下（多债少股）
- 想激进 → 选右上（多股少债）
- 永远**不选边界以下的组合**——那是"白白多承担风险"

### 3.4 边界内 vs 边界上

**边界以下的组合**：同样风险，收益更低（被支配）
**边界上的组合**：同样风险，收益最高 / 同样收益，风险最低

**MPT 的核心命题**：**永远只选有效前沿上的组合**。

## 4. 切点组合：引入无风险资产

### 4.1 无风险资产是什么

**无风险资产**：理论上没有风险的资产——通常等同于**国债**。

**性质**：
- 收益固定（如 2.5%）
- 波动率 = 0
- 与所有其他资产相关性 = 0

### 4.2 资本市场线（Capital Market Line, CML）

**引入无风险资产**后，所有"无风险 + 风险组合"的可行解构成一条**直线**——这条直线**与有效前沿的切点**叫**切点组合（Tangency Portfolio）**。

**核心定理**：**所有投资者都应该持有同一个"切点组合" + 不同比例的无风险资产**。

### 4.3 实操意义

| 风险偏好 | 配置 |
|---|---|
| 极保守 | 20% 切点组合 + 80% 国债 |
| 保守 | 40% + 60% |
| 平衡 | 60% + 40% |
| 进取 | 100% 切点组合 |
| 激进 | **加杠杆** —— 100% 切点 + 借钱再买切点 |

**翻译成人话**：你不用"挑组合"，你只需要选"持有多少风险资产 vs 国债"。

## 5. MPT 的现实局限

理论很美，但**5 个假设在现实中都不完美**：

### 5.1 假设 1：收益正态分布

**理论**：股票收益服从正态分布——大涨大跌概率小
**现实**：**厚尾**（fat tail）——黑天鹅事件远多于正态分布预测
**后果**：MPT **低估极端损失风险**（2008、2020 等）

### 5.2 假设 2：相关性稳定

**理论**：相关性 ρ 固定
**现实**：**危机时所有相关性趋于 1**——大家一起跌
**后果**：分散化在最需要的时候**失效**

### 5.3 假设 3：投资者完全理性

**理论**：投资者按最优数学决策
**现实**：投资者**追涨杀跌 + 情绪驱动**（详见第 35 章行为金融）

### 5.4 假设 4：没有交易成本和税

**理论**：自由再平衡
**现实**：交易费 / 印花税 / 资本利得税都吃掉收益

### 5.5 假设 5：可以做空 + 加杠杆

**理论**：可以无限制做空 / 借钱
**现实**：散户做空有门槛、加杠杆受限

### 5.6 修正版 MPT

学术界后续发展了**修正版 MPT**：
- 考虑厚尾（如 CVaR Conditional Value at Risk）
- 考虑动态相关性（DCC 模型）
- 引入行为偏差（行为投资组合理论）

**对散户**：知道 MPT 有局限 → **不要盲目相信"数学最优解"** → 留出"安全边际"。

## 6. 实操：用 Excel 算两资产组合

### 6.1 假设场景

**资产 A（沪深 300）**：年化 8%，波动率 22%
**资产 B（中长期纯债基）**：年化 4%，波动率 4%
**相关性 ρ = -0.10**

### 6.2 计算不同权重组合

| 权重 A | 权重 B | 组合收益 | 组合波动率 | 夏普比率 |
|---:|---:|---:|---:|---:|
| 0% | 100% | 4.0% | 4.0% | 0.5（假设无风险利率 2%）|
| 20% | 80% | 4.8% | 5.0% | 0.56 |
| 40% | 60% | 5.6% | 8.6% | 0.42 |
| **60%** | **40%** | **6.4%** | **13.2%** | **0.33** |
| 80% | 20% | 7.2% | 17.6% | 0.30 |
| 100% | 0% | 8.0% | 22.0% | 0.27 |

### 6.3 Excel 公式

```excel
组合收益 = w_A * 8% + w_B * 4%
组合波动率 = SQRT(w_A^2 * 22%^2 + w_B^2 * 4%^2 + 2 * w_A * w_B * (-0.10) * 22% * 4%)
夏普比率 = (组合收益 - 无风险) / 组合波动率
```

### 6.4 找出"最大夏普"组合

**从表中**：20%/80% 组合的夏普 0.56 最高 → **这是"切点组合"**。

**结论**：对这个 A/B 资产对，**最优风险/收益比是 20% 股 + 80% 债**。

### 6.5 但这不是唯一答案

实际选择还要看：
- 你的风险偏好（夏普最优 ≠ 最适合你）
- 时间地平（年轻多配股，老年多配债）
- 现金流需求（要不要分红 / 利息）

## 7. 进阶讨论

**入门读者可以跳过本节**。

### 7.1 多资产 MPT 优化

3+ 资产的 MPT 需要**矩阵运算**：

$$
\sigma_p^2 = \mathbf{w}^T \boldsymbol{\Sigma} \mathbf{w}
$$

其中 $\mathbf{w}$ 是权重向量、$\boldsymbol{\Sigma}$ 是协方差矩阵。

**Excel 用 Solver 求解**：
1. 输入资产收益、波动率、相关性矩阵
2. 用矩阵公式算组合方差
3. 用 Solver 在"目标收益约束"下最小化方差

详见 §延伸阅读。

### 7.2 不等式约束

**实务中的约束**：
- 单一资产 ≤ 30%
- 不允许做空（权重 ≥ 0）
- 行业上限
- 流动性约束

**这些约束让"理论有效前沿"打折扣**——但更现实。

### 7.3 Black-Litterman 模型

**问题**：MPT 对"输入参数"（预期收益）极度敏感——略改一点结果就大变。

**Black-Litterman**：从市场均衡出发，**结合投资者主观观点**给出更稳健的组合。

**应用**：高盛 / 桥水等机构的实际工具。

### 7.4 风险平价（Risk Parity）

**桥水 All Weather** 的理念：**每个资产对组合的"风险贡献"相等**，而不是"权重相等"。

例：股票波动大 → 股票权重低；债券波动小 → 债券权重高。

**结果**：典型的桥水组合是 **40% 股 + 60% 债** —— 看起来保守但风险贡献均衡。

### 7.5 因子模型替代 MPT

**实务派**越来越用**因子模型**（详见第 34 章）代替 MPT：
- 不用估计每对资产的相关性（爆炸式增长）
- 直接对几个核心因子（市场、规模、价值、动量、质量）暴露
- 更稳健、更可解释

## 8. 小结

1. **马科维茨发现**：两个高风险资产合在一起可能比单个低风险更稳——只要它们**相关性 ρ < 1**。
2. **分散化的边际递减**：20-50 只不相关资产 ≈ 95% 分散效应。再多边际很小。
3. **相关性 ρ 是核心**：ρ = 1 完全同步、ρ = 0 不相关、ρ = -1 完全对冲（理论）。**散户用国内股 + 海外股 + 债 + 黄金**实现实际分散。
4. **有效前沿**：在所有可行组合中，**只有边界上的组合是最优**——同样风险下收益最高。
5. **切点组合 + 无风险资产**：所有投资者持有同一个切点组合 + 不同比例国债 = 不同风险偏好。
6. **MPT 5 个假设都不完美**：正态分布 / 相关性稳定 / 完全理性 / 无成本 / 无约束——所以留**安全边际**。
7. **Excel 算法**：组合收益 = 加权和；组合方差 = $\mathbf{w}^T \boldsymbol{\Sigma} \mathbf{w}$；夏普 = (收益-无风险)/波动率。**Solver 求最优**。
8. **进阶方向**：Black-Litterman / 风险平价 / 因子模型 —— MPT 之后的实务工具。

> 🔗 **承上启下**：MPT 告诉你"组合怎么搭"。但**单个资产的预期收益怎么算**？为什么"高 Beta 的股票收益更高"？下一章 **34 CAPM 与因子模型** 回答这个问题。

1. **MPT 核心**：**通过分散化，可以"无成本"降低组合风险**——只要资产间相关性 ρ < 1。**诺奖原因**：① 用数学严格证明了"分散化"是免费午餐 ② 给出了"如何最优分散"的算法（有效前沿）③ 奠定了现代资产配置 / 基金管理 / 养老金的理论基础。

2. **系统性风险**：影响整个市场的风险——经济衰退、加息、战争。**非系统性风险**：单个资产 / 行业的风险——CEO 离职、公司财报。**只有非系统性风险可以通过分散消除**；系统性风险**永远存在**，是组合的"地板"。

3. **ρ = -0.5 更好**。负相关意味着两资产走势相反，**互相对冲**——组合方差中的相关项是负数，进一步降低组合波动率。正相关只是"不完全同步"，分散效果不如负相关。**实务**：找到负相关资产较难（股 vs 债部分时段、黄金 vs 美元），多数情况是低正相关（0.1-0.5）。

4. 组合收益 = 50% × 10% + 50% × 6% = **8%**
   组合方差 = 0.5² × 25%² + 0.5² × 8%² + 2 × 0.5 × 0.5 × 0 × 25% × 8%
            = 0.25 × 0.0625 + 0.25 × 0.0064 + 0
            = 0.015625 + 0.0016
            = 0.017225
   组合波动率 = √0.017225 = **13.1%**
   **对比**：单独持有 A 波动 25%、单独持有 B 波动 8%、组合 13.1%。**分散降低了波动**。

5. **含义**：有效前沿上的每个组合，在它的"风险水平"下，**收益是最高的**——同样风险下没有任何组合能给你更高收益。**避开边界以下的组合**：这些组合在同样风险水平下，**收益更低** —— 你白白多承担了风险却没有得到对应回报。**理性投资者**永远不应该选边界以下的组合。
