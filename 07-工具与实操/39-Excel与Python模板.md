## 1. Excel 必备金融函数

### 1.1 七大金融函数总览

| 函数 | 用途 | 例子 |
|---|---|---|
| **FV** | 未来值 | "现在每月存 5000，30 年后有多少" |
| **PV** | 现值 | "30 年后要 500 万，今天需要多少" |
| **PMT** | 月供 / 年金 | "贷款 200 万 30 年月供多少" |
| **RATE** | 利率 | "已知月供和总额，反推年化" |
| **NPER** | 期数 | "存多少年能到 1000 万" |
| **NPV** | 净现值 | 评估投资项目 |
| **XIRR** | 真实年化 | 不规则现金流（见第 38 章）|

### 1.2 FV：未来值

**语法**：`=FV(利率, 期数, 定期支付, [现值], [类型])`

**例 1：从零开始月存 5000，30 年后**
```excel
=FV(6%/12, 30*12, -5000, 0, 0)
= 5,022,575 元
```

**例 2：已有 100 万，再月存 5000，30 年后**
```excel
=FV(6%/12, 30*12, -5000, -1000000, 0)
= 11,045,150 元
```

**注意**：
- 利率要**和期数单位一致**（月用 6%/12，年用 6%）
- **负号表示流出**（你存钱），结果正号 = 拿回来
- "类型" 0 = 期末（月底存），1 = 期初（月初存）

### 1.3 PV：现值

**语法**：`=PV(利率, 期数, 定期支付, [未来值], [类型])`

**例 1：30 年后要 500 万，今天一次存多少（年化 6%）**
```excel
=PV(6%, 30, 0, -5000000)
= 870,956 元
```

**例 2：30 年后要 500 万，月存多少（年化 6%）**
```excel
=PMT(6%/12, 30*12, 0, -5000000)
= 4,978 元/月
```

### 1.4 PMT：月供

**语法**：`=PMT(利率, 期数, 现值, [未来值], [类型])`

**例：贷款 200 万、30 年、年利率 4.5%**
```excel
=PMT(4.5%/12, 30*12, 2000000)
= -10,134 元/月
```

**月供 10,134 元**——这就是房贷月供算法。

### 1.5 RATE：反推利率

**语法**：`=RATE(期数, 定期支付, 现值, [未来值], [类型])`

**例：你 10 年存 50 万、终值 80 万，年化是多少**
```excel
=RATE(10, -50000, 0, 800000)
= 7.05% （年化）
```

### 1.6 NPER：算期数

**语法**：`=NPER(利率, 定期支付, 现值, [未来值])`

**例：月存 5000、年化 6%、攒到 500 万要多久**
```excel
=NPER(6%/12, -5000, 0, 5000000)
= 360.42 月 ≈ 30 年
```

### 1.7 XIRR（详见第 38 章）

```excel
=XIRR(现金流范围, 日期范围, [初始猜测])
```

### 2.1 基础模板

| A 列 | B 列 |
|---|---|
| 起始本金 | 0 |
| 月投入 | 5000 |
| 年化率 | 6% |
| 投资年数 | 30 |
| **未来值** | **=FV(B3/12, B4*12, -B2, -B1)** |

### 2.2 进阶版：含通胀调整

| A 列 | B 列 |
|---|---|
| 月投入（今天购买力） | 5000 |
| 名义年化率 | 6% |
| 通胀率 | 3% |
| **实际年化** | `=(1+B2)/(1+B3)-1` ≈ **2.91%** |
| 投资年数 | 30 |
| **未来值（今天购买力）** | `=FV(B4/12, B5*12, -B1)` |

**为什么要算"今天购买力"**：30 年后 500 万的购买力 ≠ 今天 500 万。

### 2.3 月度回测表

**展开 360 行**：

| 月份 | 月初余额 | 月投入 | 月收益 | 月末余额 |
|---|---:|---:|---:|---:|
| 1 | 0 | 5,000 | 0 | 5,000 |
| 2 | 5,000 | 5,000 | 25 | 10,025 |
| 3 | 10,025 | 5,000 | 50.13 | 15,075.13 |
| ... | ... | ... | ... | ... |
| 360 | ... | ... | ... | **5,022,575** |

**月收益公式**：`= 月初余额 × (年化率/12)`
**月末余额**：`= 月初余额 + 月投入 + 月收益`

**这种"展开" 方便你看每个月的演变**。

## 3. 资产配置计算器

### 3.1 两资产组合模板

| 输入 | 值 |
|---|---|
| 资产 A 年化 | 8% |
| 资产 A 波动率 | 22% |
| 资产 B 年化 | 4% |
| 资产 B 波动率 | 4% |
| 相关性 ρ | -0.10 |
| 无风险利率 | 2.5% |

**计算（让权重 A 在 0-100% 变化）**：

| 权重 A | 权重 B | 组合收益 | 组合波动率 | 夏普比率 |
|---:|---:|---|---|---|
| 0% | 100% | 4% | 4% | 0.375 |
| 10% | 90% | 4.4% | 4.0% | 0.475 |
| 20% | 80% | 4.8% | 4.7% | **0.489** |
| 30% | 70% | 5.2% | 6.4% | 0.422 |
| ... | ... | ... | ... | ... |

**公式**：
```excel
组合收益 = 权重A × 收益A + 权重B × 收益B
组合波动率 = SQRT(权重A^2 × 波动A^2 + 权重B^2 × 波动B^2 + 2 × 权重A × 权重B × ρ × 波动A × 波动B)
夏普 = (组合收益 - 无风险)/组合波动率
```

**找最大夏普行** = 最优配置（在这个例子是 20% A + 80% B）。

### 3.2 三资产 + Solver 优化

**多资产 MPT 需要 Solver**：
1. 输入 3 资产的"收益、波动、协方差矩阵"
2. 设权重 $w_1, w_2, w_3$ 初值为 1/3
3. 设组合方差为目标
4. **Solver 约束**：sum=1, 每个 ≥ 0
5. 优化目标：最大化夏普

详见 §延伸阅读的 Bogleheads 模板。

## 4. 蒙特卡洛模拟

### 4.1 什么是蒙特卡洛

**蒙特卡洛模拟（Monte Carlo Simulation）**：用**随机数模拟未来路径**，得到"可能结果分布"。

**应用**：估算"未来 30 年退休账户余额的可能区间"。

### 4.2 简单版（Excel）

**假设**：月投 5000、平均年化 6%、波动率 15%、30 年。

**Excel 步骤**：

| 列 | 公式 |
|---|---|
| A | 月份（1-360）|
| B | 月收益率：`=NORMINV(RAND(), 6%/12, 15%/SQRT(12))` |
| C | 月末余额：`=前一行C + 5000 + 前一行C × B` |

**得到 1 条路径** → 最后一行是 30 年后余额。

**重复 1000 次**（用 Excel 数据表 / 重新计算）→ 得到 1000 个终值。

### 4.3 分析结果

**1000 条路径的统计**：

| 分位数 | 30 年后余额 |
|---|---|
| 10% 最差 | 250 万 |
| **25% 较差** | **320 万** |
| **50% 中位数** | **480 万** |
| **75% 较好** | **710 万** |
| 90% 最好 | 1,050 万 |

**翻译成人话**：
- **不要相信"单一数字"**——未来是分布
- **中位数 480 万** = "最有可能的结果"
- **80% 概率落在 250-1050 万之间** —— **范围非常大**

### 4.4 蒙特卡洛的洞察

| 观察 | 启示 |
|---|---|
| **结果分布厚尾** | 退休准备应"按 25 分位"做（保守）|
| **波动率影响巨大** | 同样年化 6%，波动 10% vs 20% 终值差距 30%+ |
| **早期亏损序列风险** | 头几年大跌的路径 → 终值远低于平均 |

### 4.5 Python 实现

```python
import numpy as np

# 参数
years = 30
months = years * 12
monthly_contribution = 5000
annual_return = 0.06
annual_vol = 0.15
n_simulations = 10000

# 模拟
results = []
for _ in range(n_simulations):
    balance = 0
    for _ in range(months):
        monthly_return = np.random.normal(annual_return/12, annual_vol/np.sqrt(12))
        balance = balance * (1 + monthly_return) + monthly_contribution
    results.append(balance)

# 统计
results = np.array(results)
print(f"10%: {np.percentile(results, 10):,.0f}")
print(f"50% (中位数): {np.percentile(results, 50):,.0f}")
print(f"90%: {np.percentile(results, 90):,.0f}")
```

from datetime import datetime

result = xirr(dates, cash_flows)

## 7. 进阶讨论

**入门读者可以跳过本节**。

### 7.1 Solver 求最优组合

**Excel Solver**：
1. 工具栏 → 加载项 → Solver
2. 输入决策变量（权重）
3. 设约束（权重和=1，每个 ≥ 0）
4. 设目标（最大化夏普 / 最小化方差 / 等等）
5. 求解

**详细步骤参考 Bogleheads / 量化金融教程**。

### 7.2 蒙特卡洛的局限

- **依赖正态分布假设**：实际市场厚尾
- **依赖历史回报作为输入**：未来未必重复
- **不考虑相关性结构变化**：危机时相关性趋 1

**修正方案**：
- 用历史**真实分布**（bootstrap 重抽样）
- 引入**厚尾分布**（t-分布）
- 加入**情景分析**（如"30 年发生 1 次危机"）

### 7.3 Python 高级金融库

| 库 | 用途 |
|---|---|
| **PyPortfolioOpt** | 高级组合优化（包括 Black-Litterman）|
| **QuantLib** | 衍生品定价 / 利率模型 |
| **Riskfolio-Lib** | 因子模型 + 风险预算 |
| **vectorbt** | 高频回测 |
| **akshare / tushare** | 中国市场数据 API |

1. **FV（Future Value）**：算"未来值"——给定利率、期数、定期支付，未来某点的累计金额。**应用**：定投到退休的累计金额。

2. `=PMT(4%/12, 30*12, -1000000)` ≈ **4,774 元/月**
   - 注意：利率用月利率（4%/12）+ 期数用月数（360）
   - 输入贷款金额为负数（你拿到的钱）→ 结果正数（你要还的月供）
   - 也可输入正数 1000000 → 结果负数

3. `=PMT(6%/12, 30*12, 0, -5000000)` ≈ **4,978 元/月**
   - 第 3 个参数 0 = 起始时账户为 0
   - 第 4 个参数 -5000000 = 30 年后要的目标
   - 结果正数 = 每月需要存入的钱

4. **RATE** 反推"年化利率"——已知期数、月供、本金、未来值。
   **应用场景**：
   - 你 10 年共投 100 万、终值 180 万 → 反推年化（`=RATE(10, -10万, 0, 180万)` 算出年化约 ~6.05%）
   - 验证销售员说的"产品年化"是不是真的
   - 评价你过去 X 年的投资表现

5. **核心思想**：用大量随机数模拟未来路径——每条路径有不同的年回报序列——得到 1000+ 个可能终值——形成"分布"而非单一数字。
   **比单一预测有用**：
   - **承认不确定性**：未来不是"一定 6% 年化"，而是"波动的"
   - **看尾部风险**：10% 分位告诉你"最坏情况"
   - **规划保守**：按 25 分位规划，"50% 概率达到目标"变"75% 概率达到"
   - **避免乐观偏差**：单一预测往往是中位数，让人过度乐观

6. **不对，800 万不是真实结果**。
   - 月存 5000、年化 6%、30 年 → FV ≈ 502 万
   - 月存 8000、年化 6%、30 年 → FV = 502 × (8000/5000) ≈ **803 万** ✓
   - **看起来是翻倍 1.6 倍**，但实际就是 **本金 + 复利按比例放大** —— 因为输入项之间是线性关系
   - **真正反直觉的是**：月存 5000 改成 5000 + 通胀调整（每年 +3%），30 年后会更高
   - **问题里"翻倍"的说法错**：5000→8000 是 1.6 倍输入，结果也是 1.6 倍——**确实是线性的**

7. 没有标准答案。**核心检查**：
   - **每月固定时间填**（如月末或月初）——形成习惯
   - **包含所有账户**（容易遗漏的：公积金、住房贷款、车贷、保险现金价值）
   - **XIRR 用"投入 - 取出"现金流 + 当前总值**——给真实年化
   - **12 个月后看**：①净资产是否上升 ②配置是否漂移 ③XIRR 是否合理
   - **作业的真正价值**：让你**第一次直观看到自己的财富轨迹**——多数人 1 年后会发现"比想的好" 或 "比想的差"，从而调整行为
