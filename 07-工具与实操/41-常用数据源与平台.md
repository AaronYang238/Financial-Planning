## 0. 先讲个故事

**小李 2024 年想查"沪深 300 PE 历史百分位"**：
- 在**天天基金**看到："PE 12.3，历史百分位 30%"
- 在**雪球**看到："PE 11.8，历史百分位 25%"
- 在**理杏仁**看到："PE 13.1，历史百分位 35%"
- **同一时点，三个数字**

小李困惑：哪个对？

**朋友老周**告诉他：
> "**都对**——它们用了**不同口径** —— 时间窗口不同（5 年 vs 10 年）、PE 算法不同（TTM vs 静态 vs 前瞻）。**问题不是"哪个准"，而是"我用哪个一致**"。"

老周分享了他的"数据源原则"：
1. **同一指标只用一个源**——避免对比错乱
2. **关键决策用 2-3 个源交叉验证**
3. **免费数据足够 90% 散户用** —— 不必追求"机构级"

> 这章告诉你：
> 1. **数据源不是越多越好** —— 一致性 > 全面性
> 2. **5 类主流平台**：基金类 / 股票类 / 综合类 / 专业类 / 学术类
> 3. **数据中性，判断主观**——别被"自动推荐"绑架
> 4. **怎么搭建你的"信息工作流"** —— 5 分钟早晨 + 10 分钟月末

## 3. 信息源 vs 投资建议

### 3.1 关键区分

| 类型 | 性质 | 怎么用 |
|---|---|---|
| **客观数据** | 中性 | 自己分析、做决策 |
| **专家观点** | 主观 | 当作"参考"，不是结论 |
| **自动推荐** | 算法 + 商业利益 | **警惕**——可能有利益冲突 |
| **付费"研报"** | 卖方有利益 | **批判性阅读** |

### 3.2 警惕"算法推荐"

**机制**：
- APP 根据你的点击行为推荐内容
- 你点了"高收益基金" → 推荐更多"高收益"
- 你点了"利空新闻" → 推荐更多"利空"
- **形成"信息回音壁"**——你只看到符合预期的内容

**对策**：
- **主动多源 + 反向阅读**：故意看一些"和你想法相反"的内容
- **减少 APP 使用**：每天 1-2 次，不要随时看
- **关注法规 / 监管原文**：不被解读绑架

### 3.3 三类"危险信号"

| 信号 | 警惕原因 |
|---|---|
| "一定会涨"  | 没有"一定"的事 |
| "内部消息" | 多半是骗局或违法 |
| "限时优惠" | 销售套路 |
| **"X 老师推荐"** | 多半是付费推荐 |

### 3.4 几个"良心信息源"

| 平台 | 良心原因 |
|---|---|
| 雪球深度研究板块 | 多数无广告，作者多是真实持仓者 |
| 财新 | 调查报道、收费的高质量 |
| 各基金公司"投资者教育" | 不卖产品 |
| 学术研究（SSRN / 知网）| 同行评议 |

## 4. 付费 vs 免费

### 4.1 散户的免费工具够用吗

**答案**：**95% 散户用免费工具足够**。

**免费工具能做什么**：
- 实时行情（券商 APP）
- 基金数据（天天基金）
- 估值百分位（理杏仁、雪球指数估值表）
- 财报数据（基金 / 公司年报免费）
- 历史回测（部分 APP 内）

### 4.2 什么时候考虑付费

| 场景 | 推荐 |
|---|---|
| **做量化策略** | Choice / iFinD（3-5K/年）|
| **深度行业研究** | 万得（贵）|
| **跨市场对比**（A / 港 / 美）| Choice 或 万得 |
| **定制化数据 API** | Tushare Pro / AkShare |

### 4.3 性价比"中间方案"

| 选项 | 年费 | 适合 |
|---|---|---|
| **AkShare**（开源 + 免费）| 0 | 编程入门者 |
| **Tushare Pro** | 200-2000 | 量化散户 |
| **Choice 学生版** | 0（部分功能）| 学习 |
| **同花顺 iFinD** | 3K+ | 深度散户 |
| **理杏仁 Pro** | 100-300 | 估值党 |

## 5. 个人"信息工作流"

### 5.1 推荐工作流（每日 5-15 分钟）

**早晨 5 分钟**：
- 雪球热门话题 / 财新头条（不超过 5 分钟）
- 看大类资产昨晚走势（美股 / 港股）

**周末 30 分钟**：
- 看 1-2 篇财新深度文
- 检查持仓基金状态（不操作）

**月末 1 小时**：
- 更新净资产快照
- 检查资产配置偏离
- 看持仓基金的最近季报

**年末 半天**：
- 全年复盘
- 全年税务规划
- 次年配置规划

### 5.2 信息精简的原则

| 原则 | 说明 |
|---|---|
| **少即是多** | 每天 5-15 分钟，不超过 |
| **同源胜过多源** | 同指标只用 1 个源——避免对比错乱 |
| **重质不重量** | 深度 1 篇 > 浏览 100 篇 |
| **不实时看盘** | 看盘 = 心理伤害 |
| **节假日断网** | 强制脱离市场情绪 |

### 5.3 几个常见误区

| 误区 | 真相 |
|---|---|
| "信息越多决策越好" | **错** —— 信息过载 → 决策瘫痪 |
| "付费数据更准" | **不一定** —— 多数散户免费数据足够 |
| "看 KOL 跟随交易" | **危险** —— KOL 多有利益 / 时机不一致 |
| "技术指标越多越准" | **错** —— 单一指标 + 长期纪律 > 复杂技术 |

**入门读者可以跳过本节**。

| **IMF Data** | 国际金融 |

### 7.2 数据清洗的复杂性

**事实**：从 API 拿到的数据通常不能直接用——需要：
- 处理停牌 / 缺失
- 复权调整（前复权 / 后复权）
- 时区对齐
- 单位统一（万元 vs 元）

**初学者**：用现成的清洗后数据，**不要自己处理"原始"数据**。

### 7.3 数据质量评估

**怎么评价数据源质量**：
- **时效性**：实时 vs 延迟
- **准确性**：和官方数据是否一致
- **历史长度**：5 年 vs 20 年
- **粒度**：日 vs 分钟 vs 实时
- **覆盖范围**：A 股 vs 全球
- **更新频率**：实时 vs 日终

## 8. 小结

1. **5 类数据**：实时行情 / 历史 / 基本面 / 资金流 / 宏观——按需选源。
2. **数据源金字塔**：L0 入门 / L1 散户级（90% 够用）/ L2 综合财经 / L3 专业终端 / L4 原始监管。
3. **主流平台分类**：基金（天天/蛋卷/晨星）/ 股票（同花顺/雪球/理杏仁）/ 综合（财新/华尔街见闻）/ 专业（Wind/Choice）/ 学术监管（央行/证监会/国家统计局）。
4. **信息源 vs 投资建议**：数据中性，**判断主观**。警惕"算法推荐 + 付费 KOL + 限时优惠"。
5. **付费 vs 免费**：**95% 散户用免费够用**。Choice / Wind 适合做深度研究 / 量化的人。
6. **个人信息工作流**：每天 5-15 分钟 + 周末 30 分钟 + 月末 1 小时 + 年末半天。**少即是多**。
7. **API 自动化**：AkShare（免费）+ Tushare（部分免费）—— 编程入门者的进阶。
8. **核心原则**：**同指标只用一个源 + 不实时看盘 + 节假日断网**——这是健康的信息态度。

   - 万得（个人 1.5W+/年）—— 适合机构 / 深度研究
   - Choice（5K+）—— 适合深度散户 + 想做量化
   - iFinD（3K+）—— 适合入门专业
   - Tushare Pro（200-2K）—— 适合量化散户
   - 理杏仁 Pro（100-300）—— 适合估值党

4. **算法推荐对散户的危险**：
   - ① **信息回音壁**：你点了"高收益" → 算法推荐更多"高收益" → 你以为"市场都在涨" → 高位接盘
   - ② **情绪强化**：负面新闻多 → 算法推恐慌 → 你在底部割肉
   - ③ **商业利益**：推荐内容可能与平台利益相关（卖产品/广告）
   - ④ **行为操控**：通过"刚才有 X 人买"等推 → 触发 FOMO
   - ⑤ **加剧短期主义**：实时通知 → 频繁交易 → 长期失败
   **对策**：减少使用 + 主动多源 + 关注原始数据

5. **每日 5-15 分钟工作流**：
   - 早晨 5 分钟：财新头条 + 隔夜大类资产
   - 周末 30 分钟：1-2 篇深度阅读 + 持仓检查
   **背后逻辑**：
   - **多数信息是噪音** —— 5 分钟够过滤了
   - **频繁看盘 = 心理伤害 + 决策错误**
   - **"无聊"的投资 = 长期赢家**
   - 与 35 章行为金融呼应：用"制度限制时间"替代"实时反应"

6. **搭建步骤**：
   - **第 1 步：选数据源**
     - AkShare（A 股 / 黄金）+ Yahoo Finance / yfinance（标普 500）
   - **第 2 步：写 Python 脚本**
     ```python
     import akshare as ak
     hs300_pe = ak.index_value_hist_funddb(symbol="沪深300", indicator="市盈率")
     # 算百分位
     ```
   - **第 3 步：定时执行**
     - Windows 任务计划 / Linux cron
     - 每月 1 日运行
   - **第 4 步：输出**
     - 写入 Excel / 邮件给自己
     - 或者写入 Notion 仪表盘
   - **第 5 步：触发提醒**
     - 估值 < 20% 百分位 → "考虑加仓"
     - 估值 > 80% 百分位 → "考虑减仓"
   - **关键**：自动化的意义不是"省时间"，是"避免情绪干预决策"

7. 没有标准答案。**重点观察**：
   - 多数人发现自己**每天打开 5-10 个 APP**——大量同质化
   - **可以砍掉**：实时行情 APP（频繁刺激）/ 算法推荐型（抖音 / 头条理财频道）/ 多个新闻 APP（财新 + 华尔街见闻 + 36 氪 = 重复 80%）
   - **保留核心 3 个**：① 一个综合财经（财新 or 华尔街见闻）② 一个数据源（天天基金 or 雪球）③ 一个深度研究（雪球 or 集思录）
   - **作业的真正价值**：让你**意识到自己的信息消费有多浪费**——多数人减少 50% 信息后，决策质量反而提升
