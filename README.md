# 个人理财与投资实战：从入门到精通

> 一套**面向零基础小白**的系统理财 + 投资教程。46 章 + 9 篇模块复盘，从"什么是复利"一路讲到"看懂 K 线、读懂新闻、用规则养基金、独立完成资产配置决策"。
>
> **不需要任何金融背景**——只要会加减乘除，按顺序读就能懂。

这套教程想做两件事：

1. **讲清"是什么"**——系统介绍证券、基金、债券、衍生品等各类投资理财产品，以及背后的金融知识；
2. **教会"怎么做"**——手把手教你投资：**看 K 线**（配图）、**读财经新闻**、**量化与数据获取**、**养基宝（基金实战养成）**，以及各种其他玩法该不该碰。

全程以**教学口吻**展开，讲 K 线、量价、定投曲线等知识时**配示意图**帮助理解。

---

## 这套教程适合谁

- 完全没碰过理财，分不清"股票 / 债券 / 基金"的区别
- 有点积蓄，但只会放余额宝，想知道"然后呢？"
- 想真正学会**看 K 线、读新闻、做定投、用数据**，又不想被大 V 喊单带节奏
- 被理财销售、短视频大 V 弄得很焦虑，想要一套**不卖课、不卖产品**的中立知识体系
- 有一定基础，想系统补全知识框架（每章都有"进阶"小节）

**读完的衡量标准**：能独立读懂基金季报、利率走势、K 线与财经新闻，能用规则化的方法养一套基金组合，并完成自己的资产配置决策。

### 路线一：零基础完整路线（推荐）

按编号 **01 → 42 顺序读**。前置章节是后续章节的基础，不要跳。每章 30-60 分钟，每周 2-3 章，**约 4 个月读完**。

直接看 [07 工具与实操](#07-工具与实操38-42)（38-42 章）+ [术语表](GLOSSARY.md)。

已懂基础概念、只想学动手技能的，按这条线读：

> [20 技术面分析/看K线](03-权益与证券/20-技术面分析.md) → [43 看懂财经新闻](08-投资实战/43-看懂财经新闻与信息甄别.md) → [44 量化入门与数据](08-投资实战/44-量化投资入门与数据获取.md) → [45 养基宝（基金实战）](08-投资实战/45-养基宝-基金实战养成手册.md) → [46 其他投资方式](08-投资实战/46-其他投资方式与渠道速览.md)

- 每章结构：**故事开场 → 概念（白话）→ 原理（公式）→ 中国市场实操 → 进阶 → 小结 → 自测题**
- 标注"**进阶**"的小节，第一遍可以跳过，回头再读
- **自测题请动手算**——能算出来才算学会
